## 🌟 Overview

LearnSmart is designed from first principles as an **AI-powered learning and assessment platform**. Rather than treating AI as a black-box question generator, LearnSmart enforces pedagogical accuracy through:
1. **Source-Grounded Active Recall**: Ingests lecture slides and personal study notes (PDF, DOCX, TXT) into a hybrid vector + BM25 index with cross-encoder re-ranking.
2. **Two-Pass Verification**: Every question generated by an LLM is independently audited by a verifier pass to ensure factual accuracy and eliminate hallucinations.
3. **Encrypted Integrity**: Correct answer keys and explanations are encrypted symmetrically at rest (Fernet AES-128-CBC) and strictly stripped from client exam payloads.
4. **Flexible Assessment Modes**: Seamlessly toggle between low-stakes **Practice Mode** (immediate learning feedback) and **Proctored Exam Mode** (server-authoritative timer, tab-switch monitoring, strike limits).

## 🚀 Key Features

| Capability | Technical Implementation |
|---|---|
| **Multi-Provider AI Abstraction** | Structural Python `Protocol` interfaces decouple business logic from AI vendors. Run locally on **Ollama (`llama3.2`)** and **sentence-transformers (`all-MiniLM-L6-v2`)** during development; switch to OpenAI/Anthropic in production with one environment variable. |
| **Hybrid RAG Pipeline** | Merges dense embeddings with sparse **BM25** using Reciprocal Rank Fusion (RRF), re-ranked with `cross-encoder/ms-marco-MiniLM-L-6-v2` and filtered by Maximal Marginal Relevance (MMR). |
| **Answer-Key Cryptography** | Fernet authenticated symmetric encryption protects all correct answers and pedagogical explanations at rest. Exam-taking APIs project clean schemas with zero answer data. |
| **Server-Authoritative Exams** | Server-side timer calculation with a 30-second latency grace period prevents client clock manipulation. Debounced, idempotent answer autosaving (`PUT /attempts/{id}/answers`). |
| **In-Browser Proctoring** | Visibility, window blur, and fullscreen state tracking with client sequence verification, strike debouncing, and automated submission triggers. |

## 🛠️ Quick Start

### 1. Prerequisites
- **Python 3.11+**
- **Node.js 20+**
- **Ollama** installed and running locally with `llama3.2`:
  ```bash
  ollama run llama3.2
  ```

### 2. Backend Setup
```bash
cd backend
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install dependencies in editable mode
pip install -e ".[dev]"

# Configure environment
cp .env.example .env

# Run database migrations and start server
uvicorn app.main:app --reload --port 8000
```
API documentation is available at `http://localhost:8000/docs`.

### 3. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Client application will open at `http://localhost:5173`.
